# 퇴장예보 (OlPark Exit Forecast)

**올림픽공원 공연이 끝나기 전에, 나가는 길을 먼저 알려주는 서비스**
한국체육산업개발(주) 「2026 공공데이터 활용 경진대회」 출품작

- 서비스: https://jinwook-kim-dev.github.io/exit-forecast/
- 공개 JSON(챗봇·앱 연동용): `docs/data/forecast.json`, `docs/data/realtime.json`, `docs/data/endtimes.csv`

## 무엇을 하나
| 모듈 | 내용 |
|---|---|
| M0 보정 실시간 주차 | 기관 실시간 주차대수에서 밤새 빠지지 않는 미출차 기록(새벽 바닥값)을 걷어낸 실제 주차 추정 |
| M1 재차 예보 | 같은 요일형·공연장 조합의 2025년 유사 공연일 중앙값(25~75% 범위), 투어 2일차부터 1일차 실측으로 보정 |
| M2 출차 웨이브 | 공연 시작 기준 15분 단위 출차 곡선, 게이트별 분배, 여유 출차 시각 |
| M3 역 분산 | 서울교통공사 역별 시간대 승차 실측으로 공연 후 역별 혼잡 단계, 도보 시간 |
| M4 퇴장 시작 역추정 | 출차 웨이브로 공연별 실제 퇴장 시작 시각 추정(새 데이터셋) |
| M5 운영 브리핑 | 동시 종료 충돌, 정산 차로·안내 인력 권고 |
| M6 데이터 품질 | 기관 개방데이터 품질 점검 11건과 개선 제안 |

## 사용 데이터
한국체육산업개발(주): 올림픽공원 입출차정보 2025(API_CPM_008), 차량입출차·공연·날씨 연계(API_CPM_009), 입출차 정보(2024-07), 실시간 주차현황·주차장 예상 이용률, 주차장 혼잡도, 공연정보, 영문 공연정보, 월별주차현황, 자주 묻는 질문 / 서울교통공사 역별 일별 시간대별 승하차 / 기상 예보(Open-Meteo, 기상청 단기예보로 교체 예정)

## 운영 구조 (운영비 0원)
GitHub Actions가 30분마다 기관 공개 페이지의 실시간 주차대수를 기록하고, 공연 일정·날씨 예보를 반영해 `docs/data/*.json`을 다시 만든다. 화면은 GitHub Pages(정적)로 제공한다. 서버·DB가 없어 2028년까지 유지 비용이 들지 않는다.

```
python pipeline/fetch_events.py   # 공연 일정 갱신
python pipeline/logger_once.py    # 실시간 주차 1회 기록
python pipeline/build_site.py     # 예보 JSON 생성
```
